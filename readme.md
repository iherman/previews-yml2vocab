# Previewing PR-s

This is a setup for the VC, DID, and PM Working Groups. Those WGs use the [yml2vocab](https://github.com/w3c/yml2vocab/) script to generate vocabularies. However, the effective generation of these vocabulary is often done via github actions, which makes it difficult to preview the results when a Pull Request is created with changes in the vocabularies. Instead of requiring the reviewer to generate the vocabulary files locally, this directory is used to store a specific PR preview temporarily.
